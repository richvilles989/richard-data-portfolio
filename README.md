# Richard Ainiegbe — Data Analytics Portfolio

A responsive React + Vite personal data analytics portfolio starter, designed for deployment on Vercel.

## Before publishing
1. Confirm the name and email shown in `src/main.jsx`.
2. Replace the generic LinkedIn and GitHub URLs with your real profiles.
3. The project cards are explicitly labelled as concepts/illustrative visuals. Replace them with real analyses as you complete projects.
4. Update the skills section to reflect your actual level as you learn.

## Run locally
Install Node.js, then run:

```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Create a GitHub repository and upload these project files (not the zip file itself).
2. In Vercel, choose **Add New → Project** and import that repository.
3. Vercel should detect Vite automatically. Use `npm run build` as the build command and `dist` as the output directory if prompted.
4. Select **Deploy**. Vercel will assign a free `*.vercel.app` URL.
